使用说明

      
    

    
    
      
  1. 左边选一个模板，或点右上角「新建怪物 / 新建物品」。
    2. 
      
  2. 中间填表格，右侧会实时生成配置文件。
    3. 
      
  3. 点「下载 .yml」，把文件放进服务器对应目录，游戏里 /mm reload。
    4. 
    

    
几个名词

    

      
ID
英文唯一名，服务器里用它刷怪，例如 my_boss，不能有空格和中文。

      
触发器
什么时候执行，比如生成时、攻击时、死亡时。

      
效果
做什么，比如造成伤害、播放音效、发送消息。

      
目标
对谁做，比如自己、当前攻击目标、附近的玩家。
