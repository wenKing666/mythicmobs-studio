使用说明

      
    

    
    
      
  1. 左边选一个模板（也可以点「存为模板」攒自己的），或点右上角「新建怪物 / 新建物品 / 更多类型」。
    2. 
      
  2. 桌面版点「打开文件夹」选服务器的 plugins/MythicMobs，左侧直接列出全部配置，点谁编辑谁。
    3. 
      
  3. 中间填表格，右侧实时生成配置；复制 YAML 或用「保存到服务器」直接落盘。
    4. 
      
  4. 改完游戏里 /mm reload 就能生效。写错了没关系——Ctrl+Z 撤销，引用检查也会提醒。
    5. 
    

    
几个名词

    

      
ID
英文唯一名，服务器里用它刷怪，例如 my_boss，不能有空格和中文。

      
触发器
什么时候执行，比如生成时、攻击时、死亡时。

      
效果
做什么，比如造成伤害、播放音效、发送消息。wiki 的 303 个机制 / 196 条件 / 91 目标器 / 38 触发器全部在「全量目录」里，中文搜索。

      
目标
对谁做，比如自己、当前攻击目标、附近的玩家。

    

    
占位符速查

    
写消息 / 显示名时可用，点击复制。外面再包一层颜色如 <gold><trigger.name></gold>。

    

    
wiki 全量数据：302 机制 / 196 条件 / 91 目标器 / 38 触发器 / 120 粒子 / 51 AI 行为 / 14 AI 目标，9 种扩展配置类型（刷怪点、对话、过场镜头等）都有表单。
